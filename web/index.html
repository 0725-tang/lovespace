NEW MEMORY

写一篇新回忆

保存后会自动生成 Markdown 文件，放进 content/memories/。

上传的新照片会同时进入照片墙；上传优先于下拉选择。

这个入口只在本机显示；公网链接里不会出现。

ADD A PHOTO

往照片墙里加一张照片

照片会保存到 content/media/photos/，并登记进照片墙。

照片只添加到照片墙，不会自动新建一篇回忆。

A LETTER TO KEEP

写一封只给 TA 看的信

暗号只保存在本机；公开页面只会收到加密后的内容。

保存后会立刻上锁；每次打开页面都会重新加密。

DANGER ZONE

注销恋爱空间

这会删除你们的名字、相爱日期、生日、照片、回忆、留言和情书。

1 / 3 连点三次确认后才会删除

PRIVATE EDITING

管理这个空间

输入管理密码后，可以在公网链接上添加照片、写回忆和删除留言。

密码只保存在本机；公网访客不知道密码时只能浏览。
